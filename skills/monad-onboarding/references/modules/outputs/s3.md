# Output module: S3

Loaded when the user chooses S3 as a destination. **Not** index-based, so
Phase 3 doesn't run for it. The `cold-storage-archive` modifier reuses these
directives to add S3 as a second destination on every pipeline.
Monad docs: <https://app.monad.com/docs/outputs/s3>.

## What the output does (confirm with `get_output_type("s3")`)

- **Access:** prefer an **IAM role** (`role_arn`) that Monad assumes. The role's
  trust policy must allow Monad's AWS role with your Monad organization ID as
  the external ID; the docs page above has the exact trust policy to copy.
  `access_key` / `secret_key` secrets are the fallback.
- **Layout:** `bucket` and `region` (required), optional `prefix`, and
  `partition_format`: `simple date` (`2024/01/01`), `compact date`,
  `hive compliant` (`year=2024/month=01/day=01`), or `flat hive compliant`
  (`dt=2024-01-01`).
- **Format** (`format_config`): `json` (array, line, or nested), `parquet`, or
  `delimited`. **Compression:** `none` or `gzip`.
- Batching defaults (10 MB, 100,000 records, or 45 seconds, whichever comes
  first) are usually fine.

## Questions to merge into the flow

- Bucket, region, and prefix.
- Who will read the data? A query engine (Athena, Spark, a lakehouse) points to
  `parquet` with `hive compliant` partitions; a plain archive points to
  line-delimited `json` with `gzip`.
- Can they create an IAM role for Monad (recommended), or must it be access keys?

## Build directives

1. `get_output_type("s3")` to confirm settings and secrets.
2. Access method: if the intake gives `role_arn`, use it and give the user the
   trust-policy step from the docs. If it doesn't, ask in Phase 6 whether they
   can create a role; if they can't answer yet, fall back to `REPLACE_ME`
   secrets for `access_key` and `secret_key` and say in the plan that a role
   is preferred. Never invent an ARN.
3. Create the output, named for what it holds: `<env>-s3-<purpose>` for a
   primary destination, `<env>-cold-archive` when the `cold-storage-archive`
   modifier creates it.
4. Retention is a bucket lifecycle rule in AWS, outside Monad. Tell the user.
